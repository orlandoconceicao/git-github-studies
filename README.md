# Guia Prático de Git & GitHub

Este repositório reúne **anotações, comandos e arquivos de apoio** para o uso do **Git e do GitHub**, com foco em produtividade, organização de projetos e versionamento de código.

Ideal para **iniciantes** e também para quem quer ter um **material rápido de consulta** no dia a dia.

---

## Estrutura do Repositório

### .gitignore
Arquivo responsável por definir **quais arquivos e pastas não devem ser versionados** pelo Git, como:
- `node_modules`
- arquivos temporários
- configurações locais
- cache e logs

Essencial para manter o repositório limpo e profissional.

---

### Abas_github.txt
Lista e explicação das **principais abas do GitHub**, como:
- Code
- Issues
- Pull Requests
- Actions
- Projects
- Settings

Útil para entender a navegação e os recursos da plataforma.

---

### Mais_usados_git.txt
Contém os **comandos Git mais utilizados**, incluindo:
- inicialização de repositório
- versionamento de arquivos
- envio e recebimento de alterações
- histórico de commits

Perfeito como **cola rápida** no dia a dia.

---

### README.md
Arquivo principal do repositório, responsável por:
- explicar o objetivo do projeto
- documentar a estrutura
- orientar outros desenvolvedores

É a **porta de entrada** do projeto no GitHub.

---

### criar_dominio_github.txt
Passo a passo para:
- configurar **domínio personalizado**
- usar **GitHub Pages**
- vincular repositório a um domínio externo

Muito útil para portfólios e sites estáticos.

---

### readme_comandos.txt
Guia prático sobre:
- como escrever um bom `README.md`
- estrutura recomendada
- comandos e sintaxe Markdown
- boas práticas de documentação

---

## Objetivo do Repositório

- Centralizar conhecimento sobre Git e GitHub  
- Servir como material de estudo e consulta  
- Facilitar o versionamento correto de projetos  
- Ajudar na criação de repositórios mais profissionais  

---

## Requisitos

- Git instalado
- Conta no GitHub
- Editor de código (VS Code recomendado)

---

## Observações

Este repositório é **didático e prático**, focado em exemplos reais e comandos mais usados no mercado.

Sinta-se à vontade para clonar, estudar e evoluir os conteúdos.
